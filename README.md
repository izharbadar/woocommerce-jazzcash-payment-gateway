# woocommerce-jazzcash-payment-gateway
Custom WooCommerce payment gateway plugin for JazzCash integration (Card + Mobile Wallet) with IPN, secure hash generation, and transaction verification.

## Features

- JazzCash Card Redirection payment support
- JazzCash Mobile Wallet payment support
- WooCommerce checkout integration
- Secure HMAC SHA256 hash generation
- IPN callback support
- Admin transaction status inquiry
- Sandbox and live mode support
- Order status auto update after payment
